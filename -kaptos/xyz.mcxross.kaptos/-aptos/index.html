Aptos

class Aptos(val settings: AptosConfig = AptosConfig()) : AutoCloseable

Kotlin-native, namespaced entry point for Aptos APIs.

Use aptos for one workflow so clients and SDK-owned accounts are cleaned up automatically. Construct this class directly when an application needs a long-lived client.
